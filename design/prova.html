o contrato (para o código)

Motor: `data/prova.js` — registo puro `{ id → resolver(profile) → { titulo, lawTag, resumo(pt/en), artigo, vigencia?, url } }`; crew-aware pelo MESMO caminho do AE (companhia + isPilot → SNPVAC/SPAC/TAP…; FTL/radiação = universal); URLs = reutilizar `AE_DEEPLINKS`/`FTL_SOURCES`/`RADIATION_SOURCES` da Biblioteca (uma fonte de verdade, zero URLs novos). · Golden `test:prova`: toda a entrada tem artigo+resumo+URL oficial (domínios da Biblioteca) · easyJet cabine ≠ pilotos (Art. 53.º ≠ o do SPAC) · universais iguais p/ os dois tipos · sem companhia AE → entradas AE ausentes (nunca se inventa). · UI: `ProvaSheet` (PeleSheet genérica, 1 componente) + o `§ artigo` INLINE no sub das linhas (passe do designer: a pílula MORREU — quando todas as linhas têm etiqueta, a etiqueta é papel de parede; inline é metadado). Linha inteira tocável (≥44pt). Âmbito: DutyDetail · folhas dos Números · Extras — a SIMULAÇÃO fica FORA (o veredicto não é dossier). O artigo aparece UMA vez na folha (na artline com a vigência; a lawTag é só a identidade do acordo).
